; title screen palette (DATA_F227 in rom.s).  The ROM only uploads the backgrounds and SP0 (20 bytes), so
; SP1-SP3 keep the gameplay colors when the game comes back to the title; the title screen doesn't use
; them.  (At power-on they hold the start-up values instead, so the first title screen isn't detected;
; SetDefaultPalette in Main.s starts with this palette current, so its layout is used anyway.)
BG0: $0F $16 $16 $16
BG1: $0F $27 $27 $27
BG2: $0F $30 $2C $12
BG3: $0F $30 $29 $19
SP0: $0F $35 $35 $35
SP1: $0F $30 $27 $19
SP2: $0F $30 $27 $16
SP3: $0F $2C $12 $25
